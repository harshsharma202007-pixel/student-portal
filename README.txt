STUDENT ACADEMIC MANAGEMENT SYSTEM

Technology:
- Python
- Flask
- SQLite
- HTML
- CSS

HOW TO RUN:
1. Install Python.
2. Open this project folder in VS Code.
3. Open Terminal in this folder.
4. Run:
   pip install -r requirements.txt
5. Run:
   python app.py
6. Open the address shown in terminal, normally:
   http://127.0.0.1:5000
